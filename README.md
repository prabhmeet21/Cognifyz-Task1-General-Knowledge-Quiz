# General Knowledge Quiz Game

A simple and interactive **text-based General Knowledge Quiz Game** developed using Python as part of the **Cognifyz Technologies Software Development Internship – Level 1 Task 1**.

## Project Overview

The General Knowledge Quiz Game is a console-based application that presents the user with multiple-choice questions. The user selects an answer for each question, and the program immediately checks the answer and provides feedback.

At the end of the quiz, the application displays the total score, correct answers, wrong answers, percentage, and a performance message.

## Features

- 10 General Knowledge questions
- Multiple-choice options: A, B, C, and D
- Input validation
- Immediate correct/incorrect feedback
- Automatic score tracking
- Correct answer count
- Wrong answer count
- Percentage calculation
- Performance message
- Play Again option
- Simple and user-friendly console interface

## Technologies Used

- Python
- Functions
- Lists and Dictionaries
- Conditional Statements
- For Loops
- While Loops
- User Input and Validation

## How the Game Works

1. The program displays a welcome message.
2. The user is presented with 10 questions.
3. Each question contains four options: A, B, C, and D.
4. The user enters their selected option.
5. The program validates the input.
6. The selected answer is checked against the correct answer.
7. The program displays whether the answer is correct or wrong.
8. The score is updated automatically.
9. After all questions are completed, the final result is displayed.
10. The user can choose to play the quiz again.
