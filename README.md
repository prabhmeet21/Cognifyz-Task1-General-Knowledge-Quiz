# General Knowledge Quiz Game

## Overview

This project is a basic text-based General Knowledge Quiz Game developed as part of the **Cognifyz Technologies Software Development Internship – Level 1 Task 1**.

The game asks the user multiple-choice general knowledge questions and provides immediate feedback based on the selected answer.

## Features

* 10 General Knowledge questions
* Multiple-choice options (A, B, C, D)
* Input validation
* Immediate correct/incorrect feedback
* Automatic score tracking
* Correct and wrong answer count
* Percentage calculation
* Performance message based on the final score
* Play Again option
* Clean and user-friendly console interface

## Technologies Used

* **Python**
* Conditional statements
* Loops
* Lists and dictionaries
* Functions
* User input and validation

## How the Game Works

1. The game displays a welcome message.
2. The user is presented with 10 questions.
3. Each question has four options: A, B, C, and D.
4. The user selects an answer.
5. The program checks whether the answer is correct.
6. The score is updated automatically.
7. After all questions, the final score and percentage are displayed.
8. The user can choose to play again.
